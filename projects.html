PROOF

Deterministic invoice & receipt verification, without magic-word AI marketing.

04how everything here is built

Engineering Rules

Personal constraints I stick to across almost every repository.

01 / EXECUTION Client-Side First

If a model or verification check can run in browser memory via JavaScript, it doesn't need a cloud server.

02 / DEPENDENCIES Zero Bloat

Plain HTML, CSS, vanilla JS, and clean Python (pandas / SQLite). No heavy UI frameworks for simple pages.

03 / PRIVACY Local Data Processing

Tools like PROOF process receipts entirely on-device—zero third-party payload logging.
